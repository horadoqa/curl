CONCEITO / 05 HTTP / UPLOAD

Enviando arquivos com cURL

cURL / multipart-form-data / Upload

O que é upload?

Upload é o processo de enviar um arquivo do cliente para um servidor. Em APIs, esse recurso pode ser utilizado para enviar imagens, documentos, anexos e outros tipos de arquivos.

Comando

Para enviar um arquivo utilizando cURL, podemos utilizar o parâmetro -F: 

curl -X POST \-F "file=@/caminho/do/arquivo.jpg" \https://api.exemplo.com/upload

Entendendo a requisição

-X POST define o método HTTP como POST.

-F indica que os dados serão enviados como um formulário multipart/form-data.

file= representa o nome do campo que a API espera receber.

O caractere @ informa ao cURL que o valor deve ser lido a partir de um arquivo local.

https://api.exemplo.com/upload representa o endpoint responsável por receber o arquivo.

Caminho do arquivo

O caminho informado depois do @ deve apontar para o arquivo existente no computador. Por exemplo, em um sistema Linux: 

curl -X POST \-F "file=@/home/usuario/Downloads/foto.jpg" \https://api.exemplo.com/upload

No Windows, o caminho pode ser informado desta forma: 

curl -X POST ^-F "file=@C:\Users\Usuario\Downloads\foto.jpg" ^https://api.exemplo.com/upload
QA Note

O @ é importante porque informa ao cURL que o valor deve ser carregado de um arquivo local. Sem ele, o cURL interpreta o valor como texto, e não como um arquivo.

Enviando outros dados

Também podemos enviar outros campos do formulário junto com o arquivo. Para isso, basta utilizar o parâmetro -F novamente. 

curl -X POST \-F "file=@/caminho/do/arquivo.jpg" \-F "descricao=Foto de perfil" \https://api.exemplo.com/upload

Nesse exemplo, a requisição possui dois campos:

file — contém o arquivo que será enviado para o servidor.

descricao — contém um texto relacionado ao arquivo.

Por que multipart/form-data?

O formato multipart/form-data permite combinar arquivos e outros campos de formulário na mesma requisição HTTP.

Por isso, esse formato é bastante utilizado em APIs que possuem funcionalidades como:

• Upload de imagens.

• Upload de documentos.

• Envio de anexos.

• Importação de arquivos.

Resumindo

Para enviar um arquivo utilizando cURL, podemos utilizar: 

curl -X POST \-F "campo=@/caminho/do/arquivo.extensao" \https://api.exemplo.com/upload
cURL

-F envia dados como multipart/form-data. O @ indica que o valor deve ser enviado a partir de um arquivo local.
