CONCEITO / 03 CRUD / UPDATE

PUT — Atualizando um recurso

cURL / HTTP PUT / ServeRest

O que é PUT?

O método PUT é utilizado para atualizar um recurso que já existe no servidor. No ServeRest, utilizamos o endpoint /usuarios/{_id} para informar qual usuário deverá ser atualizado.

Endpoint 

PUT https://serverest.dev/usuarios/{_id}

Comando

Para atualizar um usuário, enviamos uma requisição PUT informando o _id do registro na URL e os novos dados no body. 

curl -X PUT https://serverest.dev/usuarios/7tS9K8NxabeHLEtk \-H "Content-Type: application/json" \-d '{    "nome": "Hora do QA",    "email": "horadoqa@exemplo.com",    "password": "1q2w3e4r",    "administrador": "true"}'

Entendendo a requisição

-X PUT define explicitamente o método HTTP como PUT.

-H "Content-Type: application/json" informa ao servidor que os dados enviados no body estão no formato JSON.

-d '{...}' define o body da requisição, contendo os novos dados do usuário.

O _id utilizado na URL identifica exatamente qual registro deverá ser atualizado.

Dados enviados

Os novos dados são enviados no body da requisição em formato JSON: 

{    "nome": "Hora do QA",    "email": "horadoqa@exemplo.com",    "password": "1q2w3e4r",    "administrador": "true"}
QA Note

O _id não é enviado no body. Ele fica na própria URL e serve para indicar qual recurso será atualizado. O body contém somente os dados que serão enviados para a atualização.

Resposta de sucesso

Se o usuário for encontrado e a atualização for realizada com sucesso, o ServeRest retorna uma mensagem confirmando a alteração. 

{    "message": "Registro alterado com sucesso"}

Resumindo

O fluxo de uma atualização utilizando PUT é:

01. Informamos o método PUT.

02. Passamos o _id do usuário na URL.

03. Enviamos os novos dados no body em formato JSON.

04. O servidor localiza o usuário pelo _id.

05. O servidor atualiza os dados do recurso.

CRUD

PUT = Update (Atualizar). No CRUD, o PUT é utilizado para modificar um recurso que já existe no servidor.
