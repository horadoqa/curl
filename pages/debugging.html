Debugging com cURL

cURL / Verbose Mode

O que é Debugging?

Durante o desenvolvimento e os testes de uma API, muitas vezes precisamos entender o que está acontecendo durante uma requisição HTTP.

O cURL possui a opção -v, também conhecida como verbose, que permite visualizar informações detalhadas sobre o processo de comunicação entre o cliente e o servidor.

Comando 

curl -v https://serverest.dev/usuarios

Informações exibidas

Ao utilizar o -v, o cURL exibe informações adicionais sobre a comunicação HTTP, permitindo acompanhar diferentes etapas da requisição.

  • A tentativa de conexão com o servidor.
  • A resolução do DNS, que transforma o domínio em um endereço IP.
  • O estabelecimento da conexão.
  • Os headers enviados pelo cliente.
  • A requisição HTTP enviada ao servidor.
  • Os headers recebidos na resposta.
  • O status code retornado pelo servidor.
  • O conteúdo da resposta.

Exemplo de saída

A saída do modo verbose pode apresentar informações semelhantes às seguintes: 

* Host serverest.dev:443 was resolved.* Connected to serverest.dev> GET /usuarios HTTP/1.1> Host: serverest.dev> Accept: */*>< HTTP/1.1 200 OK< Content-Type: application/json<{    "quantidade": 2,    "usuarios": [...]}

Entendendo os símbolos

Os símbolos exibidos pelo modo verbose ajudam a identificar o fluxo da comunicação entre o cliente e o servidor.

Símbolo Significado
* Informações sobre o processo de conexão realizado pelo cURL.
> Informações que estão sendo enviadas pelo cliente para o servidor.
< Informações que estão sendo recebidas do servidor.

Requisição enviada

Por exemplo, a linha: 

> GET /usuarios HTTP/1.1

indica que o cliente enviou uma requisição GET para o endpoint /usuarios.

Resposta recebida

Já a linha: 

< HTTP/1.1 200 OK

indica que o servidor respondeu com o status 200 OK, informando que a requisição foi processada com sucesso.

Quando utilizar o -v?

O modo verbose é especialmente útil quando uma requisição não está funcionando como esperado.

Podemos utilizar o -v para investigar:

  • Erros de conexão.
  • Problemas de DNS.
  • Headers incorretos.
  • Problemas de autenticação.
  • Redirecionamentos.
  • Status HTTP inesperados.
  • Problemas de comunicação entre cliente e servidor.

Exemplo de debugging

Ao executar uma requisição com -v, podemos acompanhar o fluxo completo da comunicação:

Resumindo

A opção: 

curl -v <URL>

ativa o modo verbose do cURL e permite acompanhar com mais detalhes o processo de uma requisição HTTP.

O modo verbose ajuda a identificar em qual etapa da comunicação pode estar ocorrendo um problema, desde a resolução do domínio até a resposta enviada pelo servidor.

QA Note

O -v é uma ferramenta muito útil para debugging e troubleshooting de APIs. Quando uma requisição não apresenta o comportamento esperado, o modo verbose permite observar detalhes da comunicação entre o cliente e o servidor e investigar problemas de conexão, DNS, headers, autenticação e status HTTP.
