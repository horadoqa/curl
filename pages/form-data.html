Enviando Form Data

cURL / Multipart Form Data

O que é Form Data?

O Form Data é uma forma de enviar informações para uma API utilizando o formato multipart/form-data.

No cURL, utilizamos a opção -F, também conhecida como --form, para enviar os campos do formulário.

Comando 

curl -X POST \ -F "email=horadoqa@qa.com" \ -F "password=1q2w3e4r" \ https://serverest.dev/login

Entendendo o comando

  • -X POST define o método HTTP como POST.
  • -F envia um campo utilizando multipart/form-data.
  • email=horadoqa@qa.com representa o campo email.
  • password=1q2w3e4r representa o campo password.

O que o cURL envia?

Quando utilizamos -F, o cURL monta automaticamente a requisição utilizando o formato multipart/form-data.

O header Content-Type é gerenciado pelo próprio cURL, incluindo o boundary necessário para separar os campos enviados. 

Content-Type: multipart/form-data; boundary=...

Form Data vs JSON

Formato cURL Content-Type
JSON -d application/json
Form Data -F multipart/form-data

Seu exemplo utilizando JSON

O exemplo utilizado anteriormente envia as credenciais como JSON: 

curl -X POST \ https://serverest.dev/login \ -H "accept: application/json" \ -H "Content-Type: application/json" \ -d '{ "email": "horadoqa@qa.com", "password": "1q2w3e4r" }'

Transformando para Form Data

Para enviar os mesmos campos utilizando Form Data, substituímos o -d por campos -F. 

curl -X POST \ -F "email=horadoqa@qa.com" \ -F "password=1q2w3e4r" \ https://serverest.dev/login

Form Data também permite arquivos

Uma das principais características do multipart/form-data é permitir o envio de arquivos junto com outros campos. 

curl -X POST \ -F "nome=Relatório de QA" \ -F "arquivo=@relatorio.json" \ https://api.exemplo.com/upload

Nesse caso, o campo nome contém um valor textual e o campo arquivo envia o arquivo localizado em relatorio.json.

Resumindo

Para enviar dados utilizando multipart/form-data, podemos utilizar: 

curl -X POST \ -F "campo1=valor1" \ -F "campo2=valor2" \ https://api.exemplo.com/endpoint
QA Note

O -F é utilizado quando a API espera dados no formato multipart/form-data. Ele é especialmente importante em cenários de upload de arquivos, onde podemos enviar arquivos e campos adicionais na mesma requisição.
