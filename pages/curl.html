CONCEITO / 01 WHAT IS CURL?

O que é cURL?

Command Line / Data Transfer

O cURL é uma ferramenta de linha de comando utilizada para transferir dados entre um cliente e um servidor.

Ele permite realizar requisições utilizando diferentes protocolos, sendo HTTP e HTTPS alguns dos mais utilizados no desenvolvimento e nos testes de APIs.

Na prática, podemos utilizar o cURL diretamente pelo terminal para enviar uma requisição, receber uma resposta e analisar o resultado dessa comunicação.

COMANDO / 01 BASIC

Comando básico

Estrutura de uma requisição 
curl <URL>
EXEMPLO / 01 REQUEST

Primeira requisição

cURL + URL 
curl https://serverest.dev
EXPLICAÇÃO / 01 HOW IT WORKS

Quando executamos esse comando, o cURL recebe a URL informada e realiza uma requisição para o servidor.

O servidor recebe essa requisição, processa a solicitação e retorna uma resposta HTTP.

Essa resposta pode conter dados, informações sobre o recurso solicitado ou detalhes sobre o resultado da operação.

QA Note

O cURL permite testar uma API diretamente pelo terminal, sem depender de uma interface gráfica. Isso torna a ferramenta muito útil para QA, desenvolvimento, automação e debugging.
