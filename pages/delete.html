A requisição DELETE é utilizada para remover um recurso existente do servidor. Neste exemplo, utilizaremos o cURL para excluir um usuário do ServeRest.

CONCEITO / 04 CRUD / DELETE

DELETE — Removendo um recurso

cURL / HTTP DELETE / ServeRest

O que é DELETE?

O método DELETE é utilizado para remover um recurso existente no servidor. No ServeRest, utilizamos o endpoint /usuarios/{_id} para indicar qual usuário deverá ser excluído.

Endpoint 

DELETE https://serverest.dev/usuarios/{_id}

Comando

Para excluir um usuário, enviamos uma requisição DELETE informando o _id do registro diretamente na URL. 

curl -X DELETE https://serverest.dev/usuarios/7tS9K8NxabeHLEtk

Entendendo a requisição

-X DELETE define explicitamente o método HTTP como DELETE.

/usuarios/7tS9K8NxabeHLEtk representa o endpoint utilizado para identificar o usuário que será removido.

O _id presente na URL permite que o servidor localize exatamente qual registro deverá ser excluído.

É necessário enviar um body?

Diferentemente das requisições POST e PUT, neste exemplo não precisamos enviar um body contendo os dados do usuário.

O _id informado na URL é suficiente para que o servidor identifique o recurso que deverá ser removido. 

curl -X DELETE https://serverest.dev/usuarios/7tS9K8NxabeHLEtk
QA Note

No DELETE, o _id é a informação principal para identificar o recurso. Por isso, neste exemplo, não precisamos enviar os dados do usuário no body da requisição.

Resposta de sucesso

Quando a exclusão é realizada com sucesso, o ServeRest retorna uma mensagem confirmando a operação. 

{    "message": "Registro excluído com sucesso"}

Resumindo

O fluxo para excluir um usuário utilizando DELETE é:

01. Utilizamos o método DELETE.

02. Informamos o endpoint /usuarios.

03. Passamos o _id do usuário na URL.

04. O servidor localiza o usuário pelo _id.

05. O registro é removido.

06. O servidor retorna uma mensagem confirmando a exclusão.

CRUD

DELETE = Delete (Excluir). No CRUD, o DELETE é responsável por remover um recurso existente do servidor.
