cURL / File Upload

Enviando arquivos com cURL

O cURL também pode ser utilizado para realizar upload de arquivos para uma API.

Para esse tipo de operação, podemos utilizar a opção -F, que permite enviar dados utilizando o formato multipart/form-data.

Comando 

curl -X POST \  -F "arquivo=@relatorio.json" \  https://api.exemplo.com/upload

Entendendo a requisição

Nesse comando, cada parte possui uma função específica dentro da requisição HTTP.

Parte Função
-X POST Define o método HTTP como POST.
-F Envia dados utilizando multipart/form-data.
arquivo Define o nome do campo recebido pela API.
@relatorio.json Indica que o conteúdo será obtido de um arquivo.
/upload Endpoint responsável por receber o arquivo.

O significado do @

O caractere @ possui uma função importante no upload realizado pelo cURL. 

-F "arquivo=@relatorio.json"

O arquivo representa o nome do campo esperado pela API.

Já o @relatorio.json informa ao cURL que o valor desse campo deve ser obtido a partir do arquivo existente no computador.

Arquivo utilizado

Antes de executar o comando, precisamos ter o arquivo disponível no diretório atual. 

lsrelatorio.json

Nesse exemplo, o arquivo relatorio.json está no mesmo diretório onde o comando será executado.

Enviando um arquivo de outra pasta

Também podemos informar o caminho até o arquivo. 

curl -X POST \  -F "arquivo=@./arquivos/relatorio.json" \  https://api.exemplo.com/upload

Nesse caso, o arquivo está localizado dentro do diretório arquivos.

Enviando mais de um arquivo

Dependendo do contrato da API, também podemos enviar múltiplos arquivos utilizando vários campos -F. 

curl -X POST \  -F "arquivo1=@relatorio.json" \  -F "arquivo2=@evidencias.png" \  https://api.exemplo.com/upload

Arquivo + outros campos

Uma requisição multipart também pode conter campos adicionais além do arquivo. 

curl -X POST \  -F "arquivo=@relatorio.json" \  -F "descricao=Relatório de testes" \  https://api.exemplo.com/upload

Nesse exemplo, a requisição possui um arquivo e também um campo chamado descricao.

Content-Type

Ao utilizar -F, o cURL configura a requisição como multipart/form-data.

Diferentemente de uma requisição JSON, não precisamos montar manualmente o header Content-Type com o boundary utilizado no multipart. 

-F "arquivo=@relatorio.json"

O cURL cuida da estrutura necessária para o envio multipart.

Upload em testes de API

Uploads são bastante comuns em sistemas que trabalham com documentos, imagens, relatórios e evidências. Em QA, podemos automatizar diferentes cenários.

  • Validar o upload de um arquivo válido.
  • Testar arquivos com extensões não permitidas.
  • Testar arquivos acima do tamanho permitido.
  • Validar o comportamento quando nenhum arquivo é enviado.
  • Verificar o nome e o tipo do arquivo recebido.
  • Validar o Status Code retornado pela API.
  • Verificar a mensagem retornada após o upload.

Upload + Status Code

Assim como nas outras requisições, podemos capturar o Status Code retornado pela API. 

STATUS=$(curl -s \  -o resposta.json \  -w "%{http_code}" \  -X POST \  -F "arquivo=@relatorio.json" \  https://api.exemplo.com/upload)echo "Status Code: $STATUS"

Validando o upload

Podemos utilizar o Status Code para determinar se o upload foi processado conforme esperado. 

STATUS=$(curl -s \  -o resposta.json \  -w "%{http_code}" \  -X POST \  -F "arquivo=@relatorio.json" \  https://api.exemplo.com/upload)if [ "$STATUS" -eq 200 ]; then  echo "Upload realizado com sucesso"else  echo "Falha no upload - Status: $STATUS"  exit 1fi

Upload vs Download

O cURL pode trabalhar tanto com o envio quanto com o recebimento de arquivos.

Operação Exemplo Função
Upload -F "arquivo=@arquivo.json" Envia um arquivo para a API.
Download -O Baixa um arquivo disponibilizado pela API ou servidor.

Resumindo

Para realizar um upload utilizando cURL, podemos utilizar a opção -F: 

curl -X POST \  -F "arquivo=@relatorio.json" \  https://api.exemplo.com/upload

O -F permite enviar dados no formato multipart/form-data, enquanto o caractere @ indica que o valor será obtido de um arquivo local.

QA Note

Upload de arquivos é um cenário importante em testes de API. Com o cURL, podemos enviar arquivos, combinar arquivos com outros campos, capturar o Status Code e automatizar validações utilizando if, jq e exit 1.
