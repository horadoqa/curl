Visualizando Cabeçalhos

cURL / Response Headers

O que são Headers?

Em uma requisição HTTP, os headers carregam informações importantes sobre a comunicação entre o cliente e o servidor.

No cURL, podemos utilizar a opção -i, também conhecida como --include, para exibir os cabeçalhos da resposta HTTP junto com o corpo da resposta.

Comando 

curl -i https://serverest.dev/usuarios

Exemplo de Resposta

Ao utilizar o -i, o cURL exibirá primeiro os headers retornados pelo servidor e, em seguida, o conteúdo da resposta. 

HTTP/1.1 200 OKContent-Type: application/jsonContent-Length: 123Date: Mon, 10 Aug 2026 10:00:00 GMT{    "quantidade": 2,    "usuarios": [...]}

Entendendo a Resposta

A primeira linha representa o status da resposta HTTP. 

HTTP/1.1 200 OK

O status 200 OK indica que a requisição foi processada com sucesso.

Já o header Content-Type informa o formato do conteúdo retornado pelo servidor: 

Content-Type: application/json

Nesse caso, o servidor informa que o conteúdo da resposta está no formato JSON.

Headers e Body

Depois dos headers existe uma linha em branco que separa os cabeçalhos do corpo da resposta. 

Content-Type: application/json{    "quantidade": 2,    "usuarios": [...]}

Opção -i

A opção -i inclui os headers da resposta na saída do cURL juntamente com o corpo. 

curl -i https://serverest.dev/usuarios

Essa opção é útil quando queremos verificar rapidamente informações como status code, Content-Type, Content-Length, cookies e outros headers retornados pelo servidor.

Opção -v

O -v, de verbose, apresenta informações mais detalhadas sobre a comunicação entre o cURL e o servidor. 

curl -v https://serverest.dev/usuarios

O modo verbose permite observar informações como conexão, requisição enviada, headers enviados e headers recebidos.

Por isso, essa opção é especialmente útil quando estamos realizando debugging de uma requisição.

-i vs -v

Opção Utilização
-i Inclui os headers da resposta junto com o corpo retornado pelo servidor.
-v Exibe informações detalhadas sobre a comunicação HTTP, incluindo requisição, resposta e conexão.

Resumindo

Para visualizar os headers da resposta junto com o corpo, podemos utilizar: 

curl -i <URL>

O -i é útil para observar rapidamente os headers retornados pelo servidor.

Já o -v fornece informações mais detalhadas sobre todo o processo de comunicação HTTP.

QA Note

Durante testes de API, o -i é útil para verificar rapidamente o status e os headers retornados pelo servidor. Quando precisamos investigar a comunicação com mais detalhes, o -v permite acompanhar informações adicionais da requisição e da resposta.
